# Contributing

This repository is a personal HTML learning sandbox.

## Before making a change

1. Open the relevant HTML file and understand the existing exercise.
2. Keep examples small and focused on the concept being practised.
3. Avoid committing passwords, API keys, personal data, or generated build output.

## Verify your change

Open `index.html` in a browser, or run `python -m http.server 8000` from the repository root and check the page at `http://localhost:8000`.

There is currently no automated test suite or build system.

## Pull requests

Use a short, descriptive branch and commit message. Explain what the exercise demonstrates and include screenshots for visible changes when useful.
